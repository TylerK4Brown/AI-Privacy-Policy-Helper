# Purpose of this folder
The goal is to have our LLM generate Streamlit code that converts summaries of a privacy policy into a well-formatted webpage that describes the privacy policy in a more user-friendly manner.

In order to do this, our code will have to create a Python file using the generated code output from the LLM.

This folder will house all generated Python code outputs from our program.

# How will we do this?

Python's [os library](https://www.geeksforgeeks.org/python/create-an-empty-file-using-python/) is extremely useful for this case. We'll be able to directly append the generated Python code to a file that we create programatically. 

When the project gets to this step, this folder will make more sense, but for now it is a placeholder and a basic explanation of what will be happening at this stage of the project.
